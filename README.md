# Business Process Mining & Bottleneck Analysis

A Python-based application for analyzing business process execution from event logs and identifying workflow bottlenecks.

## Features

- Event log ingestion and validation
- Process discovery and activity transition analysis
- Activity duration and bottleneck analysis
- REST APIs for process analytics
- Automated testing

## Tech Stack

- **Language:** Python
- **Backend:** Django REST Framework
- **Data Processing:** pandas
- **Database:** SQLite
- **Testing:** pytest
